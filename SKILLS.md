# Development skill library

This file is the required project skill index. Before feature work, read the
full index, select the skills relevant to the task, and apply them in code and
verification. Each entry must include purpose, use case, approach, tools,
security consideration, and verification.

The first foundation task is to replace this bootstrap text with exactly 500
distinct, practical skills across the categories and counts listed in
`PLAN.md`. The library auditor must validate IDs, uniqueness, required fields,
category totals, and substantive guidance before feature agents begin.
